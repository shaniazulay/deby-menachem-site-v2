# דבי מנחם – אתר תדמית (גרסה 2)

אתר סטטי (HTML/CSS/JS, ללא שלב build), בנוי 1:1 לפי עיצוב ה-Figma "פרויקט עיסוי":
- דסקטופ – פריים `8:84` (1440px)
- מובייל – פריים `121:503` (390px)

## איך זה בנוי
| קובץ | תפקיד |
|---|---|
| `index.html` | כל התוכן (RTL, עברית). לכל אלמנט יש קואורדינטות Figma כמשתנים: `--dt/--dr/--dl/--dw/--dh` לדסקטופ ו-`--mt/--mr/--ml/--mw/--mh` למובייל |
| `styles.css` | טיפוגרפיה ורכיבים, בלוק דסקטופ (≥1100px) ובלוק מובייל (<1100px) |
| `main.js` | התאמת זום למסך, תפריט מובייל, אקורדיון שאלות, קרוסלות המלצות, טופס → וואטסאפ |
| `assets/` | אייקונים ו-SVG מה-Figma, `assets/img/` תמונות WebP מכווצות |

**רספונסיביות:** הדף הוא "במה" ברוחב העיצוב (1440 / 390) שמוגדלת/מוקטנת אוטומטית לרוחב המסך (CSS `zoom`), כך שהקומפוזיציה זהה לעיצוב בכל רוחב.
‎≥1100px – עיצוב הדסקטופ (מוגבל ל-1920px), ‎<1100px – עיצוב המובייל (מוגבל ל-546px בטאבלט, ממורכז).

## הרצה מקומית
```bash
npm run dev
```
ואז לפתוח http://localhost:3000 (הוספת `?static` לכתובת עוצרת אנימציות – משמש להשוואת פיקסלים).

## העלאה ל-Vercel
ב-Vercel: New Project ← לבחור את ה-repo ← Deploy. ההגדרות כבר ב-`vercel.json` (אתר סטטי, בלי התקנה ובלי build).
